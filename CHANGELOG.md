# Changelog

## 1.0.0 (2026-07-28)

### Features

- Dynamic form builder with 7 question types
- Cloudflare Worker backend with input validation
- Discord webhook integration with formatted embeds
- Secure admin dashboard with session-based authentication
- Submission management (view, search, filter, archive, delete, notes)
- Analytics dashboard with charts and statistics
- CSV export functionality
- Activity log for tracking administrative actions
- Rate limiting and spam protection
- Comprehensive security headers and CSP
- Responsive design for all devices
- Keyboard navigation and screen reader support
- One-file configuration for branding and questions
